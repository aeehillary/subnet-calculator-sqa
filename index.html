Kalkulator Subnet IPv4

Masukkan alamat IPv4 dan prefix untuk mengetahui subnet mask, network address, broadcast, rentang host, dan jumlah host yang dapat digunakan.

Input jaringan

Gunakan format empat oktet, misalnya 192.168.1.10.
Nilai prefix berada di antara 0 sampai 32.

Catatan: Prefix /31 menggunakan aturan point-to-point (2 host), sedangkan /32 menunjukkan satu alamat IP tunggal.

Hasil perhitungan

Hasil subnet akan muncul di sini setelah kamu mengisi alamat IP dan prefix, lalu menekan tombol Hitung subnet.
